# For Akanksha — With All My Heart 🌹

> *"Kabhi chhodne ki nhi soch sakta main aapko."*  
> *"Please waapas aa jaiye."*  
> *— aapka Krish*

A personal, heartfelt romantic apology website created with all my love, remorse, and eternal hope for **Akanksha**.

---

## ✨ Features & Experiences
- 💖 **Dedicated Landing Sanctuary:** Welcoming interactive gateway with a personal letter and 3D card experience.
- 🎨 **Cursor-Driven 3D Perspective Tilt:** Interactive cards that respond gracefully to mouse movements with dynamic perspective and subtle light sheen.
- ✨ **Fluid Cursor Trail:** A silky stardust trail of rose-pink glowing particles that dances along with the cursor.
- 🛤️ **Interactive MotionPath Waypoints:** Curved SVG journey path tracing 4 core milestones (*The Beginning*, *Shared Smiles*, *Deep Remorse*, *Forever Yours*) with a gliding heart guide.
- 💌 **Words From the Soul:** 4 sincere Hindi quotes expressing Krish's deepest feelings.
- 📸 **Memories Gallery:** Beautiful photographic moments etched in time.
- 🎵 **Our Song:** High-quality background soundtrack with a floating playback toggle.
- 🌹 **"Wapas Aa Jaiye" Call to Action:** Interactive plea with an affectionate message popup.

---

## 🛠️ Built With
- **React 18** (Functional components, Hooks, and Refs)
- **Tailwind CSS** (Dark purple aesthetic with glowing rose accents)
- **GSAP 3.12** (`MotionPathPlugin`, `quickTo`, `context`, perspective 3D animations)
